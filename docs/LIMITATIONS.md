# Limitations

*Plain language: what this benchmark cannot tell you, and where its numbers are weakest. Read this before citing anything from it.*

1. **The ceiling is for one reaction only.** The equilibrium limit assumes propane turns only into propylene and hydrogen. Real reactors also crack propane to methane, ethane and ethylene, and lay down coke. Those side reactions are not in the ceiling, so it is the standard dehydrogenation-only reference, not a full chemical equilibrium.
2. **Thermodynamic data carry small uncertainty.** The NASA data agree with an independent property library to within about 4% in the equilibrium constant between 500 and 650 °C, which moves the ceiling by less than 0.5 percentage points for pure propane at 1 bar (see `data/processed/qa_equilibrium.txt`). Equilibrium values quoted inside papers sometimes differ by much more; these are compared in `data/processed/quoted_equilibrium_check.csv`. Differences smaller than about 1 percentage point in approach-to-equilibrium should not be over-read.
3. **The ceiling is only as good as the reported temperature.** If a paper reports a furnace setpoint while the catalyst bed is cooler (the reaction absorbs heat) or hotter (some electrified heating), the ceiling is computed at the wrong temperature. The `temperature_basis` column records what each paper measured; results with `unreported` or `setpoint` basis under electrified heating are the least certain.
4. **Ideal gas, atmospheric assumption.** Where a paper gives no pressure, 1.01325 bar is assumed and marked `pressure_assumed`.
5. **Space velocity is not a full kinetic normalization.** Approach-to-equilibrium shows how close a result is to the ceiling, not how fast the catalyst is. A catalyst run at very low space velocity can reach the ceiling without being very active. Compare approach-to-equilibrium only together with WHSV.
6. **Values read from figures are less precise**, about plus or minus 1 percentage point, and are marked `figure_digitized`.
7. **Selection.** The benchmark covers the papers extracted so far, not all published work. Coverage by year, catalyst family and heating mode is reported in each release so readers can see the gaps. Positive results are more likely to be published than negative ones.
8. **Deactivation.** The common deactivation constant uses first and last points of a run and assumes first-order decay; it summarizes, but does not model, deactivation.
9. **Not checked against the original raw data.** Values are as published. The benchmark cannot detect an error the original authors made, except where the physics checks (for example, conversion above the ceiling) reveal it.
10. **Conversion includes side reactions.** Reported conversion counts propane lost to cracking and coke as well as to propylene. Cracking is not limited by the dehydrogenation equilibrium, so a catalyst with poor selectivity can report a conversion above the ceiling without any error. Compare propylene yield (`yield_C3H6_calc_pct`) with the ceiling as well.
11. **Text and tables only, so far.** Version 1.0 contains only values printed as numbers in a paper's text or tables. Papers that report results only in figures are logged in `data/extraction/screening_log.csv` and are not yet included, which biases the current set toward papers that print their key numbers.
12. **Extraction can still contain errors.** Values were entered with software assistance and checked against each paper by the curator. Automatic checks confirm each number appears in its paper and each citation matches the DOI registry. Please report any error through the repository issue tracker.
13. **Converted space velocities.** Papers report space velocity on different bases (per g catalyst, per g Pt, total feed, gas volume). Where conversion was needed, `whsv_source` is `computed` and the assumption is in `extractor_flags`.
14. **Conflict of interest.** The maintainer is a co-author of one included paper (S0017, radio-frequency heating).
15. **Open-access bias.** The first batch was drawn from open-access papers in Europe PMC, so subscription-only journals are under-represented.
